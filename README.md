# STEP Viewer

Windows x64용 CAD 뷰어 · 형식 변환 · 기본 솔리드/서페이스 편집 프로그램입니다.

## 다운로드

[최신 버전 설치](https://github.com/GilwooKim/step-viewer-releases/releases/latest)에서 `STEP-Viewer-Setup-<version>-x64.exe`를 실행하세요. Windows 10/11 x64용이며 설치 파일은 코드 서명이 없습니다.

## 자동 업데이트

2.0.1 이하 사용자는 **2.1.0 이상을 한 번 직접 설치**해야 합니다. 이후 프로그램이 실행 중이고 인터넷이 연결되어 있으면 정식 최신 버전을 확인·다운로드합니다. 작업을 저장한 뒤 정상 종료하면 업데이트를 설치합니다. 2.6.0부터 설정(Ctrl+,)에서 진행 상황과 수동 확인, 자동 확인 설정을 사용할 수 있습니다. 이전 버전은 도움말(F1)을 사용하세요.

저장 중이거나 저장하지 않은 변경 사항이 있으면 종료 보호 절차를 거칩니다. CAD 파일은 로컬에서 처리되고 업로드되지 않습니다. 설치된 사용자에게 GitHub 계정이나 토큰이 필요하지 않습니다.

## 다중 부품 삭제와 CAD 메모리 개선 (2.7.0)

일반·정밀 CAD 모드에서 Shift+클릭으로 여러 부품을 선택하고 **선택 부품 삭제**, 편집 패널의 **삭제**, 또는 **Delete** 키로 한 번에 삭제합니다. **Ctrl+Z** 한 번으로 그룹 전체와 조립 구조를 복원하고 **Ctrl+Y**로 다시 삭제합니다. 전부 삭제한 빈 문서도 프로젝트로 저장할 수 있습니다.

삭제는 남은 부품의 형상과 좌표를 그대로 보존하고 전체 모델을 재계산하지 않습니다. CAD 작업이 끝나면 계산 엔진의 메모리를 해제하여 반복 편집 후 STEP 내보내기에서 발생하던 메모리 누적 문제를 해결했습니다. 오류가 발생해도 현재 편집은 유지됩니다.

Multi-part deletion works in mesh and precision CAD modes, with atomic undo/redo. CAD engines are released after each operation to prevent accumulated native memory during edits and STEP export. Remaining exact geometry and assembly structure are preserved.

## 언어와 앱 설정 (2.6.0)

설치 시작 시 **English / 한국어**를 선택합니다. 설치 언어가 앱의 첫 실행에도 적용되며, 앱에서 이미 선택한 언어는 유지합니다. 자동 업데이트는 언어 선택 창 없이 진행하며 이전 설치 언어도 유지합니다.

실행 중 상단 **톱니바퀴**, **설정 → 언어 및 업데이트…**, 또는 **Ctrl+,**에서 표시 언어를 바꾸고 업데이트를 관리하세요. 언어는 즉시 바뀌고 다음 실행에도 유지됩니다. 열린 탭·편집·카메라·선택 상태를 유지하고, 파일명과 부품 이름은 번역하지 않습니다. 같은 창에서 새 버전 확인, 다운로드, 종료 후 설치, 자동 확인·다운로드를 사용할 수 있습니다.

English and Korean are available in both the installer and the app. Open **Settings** with the gear button or **Ctrl+,** to change language immediately and manage software updates. Your open files, edits and model names are preserved.

## 조립 트리와 부품 구분 유지 (2.5.0)

선택한 부품을 STEP으로 저장할 때 개별 부품과 필요한 상위 조립품을 기록합니다. 원본에서 확인 가능한 조립 트리를 표시하고, 가져오기 중 생략된 중간 그룹은 STEP의 제품/조립 정보를 확인하여 복원합니다. 같은 이름의 별도 조립품도 구분합니다.

원본 솔리드와 곡면을 보존하려면 **원본 STEP 열기 → 편집 → 정밀 CAD 편집 시작 → 부품 선택 → STEP 내보내기** 순서로 사용하세요. 조립품 옆 **N개 선택** 버튼과 Shift 선택을 지원하며, **분해 단위**에서 조립품 단계를 고르면 그룹 내부의 상대 위치를 유지합니다. 출력은 화면의 분해 간격과 무관하게 실제 조립 위치를 사용합니다.

보존 범위는 읽을 수 있는 부모·자식 조립 계층과 현재 부품 배치입니다. 메이트·동심·힌지 같은 운동 구속조건을 복원하거나 계산하지 않습니다. 모호한 관계는 추측하지 않습니다. 메시 STEP은 삼각형 평면이며 메시 틈 때문에 여러 서페이스로 나뉠 수 있습니다. 이미 합쳐져 구조가 사라진 파일은 원본을 다시 열어 추출하세요.

## 여러 파일을 탭으로 보기 (2.4.0부터)

여러 파일을 열거나 끌어 놓으면 각각 새 탭에 추가됩니다. 탭 클릭 또는 Ctrl+Tab / Ctrl+Shift+Tab으로 전환하고 × 또는 Ctrl+W로 닫습니다. 탭마다 시점·선택·숨김·분해도·편집·실행 취소를 유지합니다. 저장과 내보내기는 현재 탭에 적용됩니다. 수정된 탭을 닫을 때는 프로젝트 저장 여부를 확인합니다. 재실행 후 탭 자동 복원은 지원하지 않습니다.

## 부품별 별도 파일로 일괄 내보내기 (2.3.0)

Shift+클릭으로 부품 선택 → **선택 부품 내보내기** → 출력 형식 → **저장 방식: 부품별 별도 파일** → **폴더 선택 후 부품별 저장**.

폴더를 한 번만 선택하면 각 부품을 부품 이름의 개별 파일로 저장합니다. 중복되거나 기존 파일과 같은 이름에는 번호를 붙여 덮어쓰지 않습니다. 진행률과 처리 결과에서 저장한 파일명 및 실패한 부품을 확인할 수 있습니다. 중단하면 현재 부품 처리 후 멈추며 이미 저장한 파일은 유지됩니다.

전체/표시 중/선택한 부품에 적용됩니다. 13개 형식을 지원하며 각 형식의 제한은 그대로 적용됩니다. 정밀 곡면·솔리드 STEP은 정밀 CAD 모드에서 내보내세요.

## 여러 부품 선택 · 내보내기 (2.2.0)

3D 화면 또는 부품 목록에서 **Shift+클릭**으로 선택을 추가·해제합니다. 왼쪽 **선택 부품 내보내기 (N개)**를 누르고 출력 형식을 고르면 선택한 부품들만 한 파일로 저장됩니다. 일반 클릭은 한 부품만 선택하고 Esc는 전체 선택을 해제합니다. 선택만 보기·확대도 여러 부품에 함께 적용됩니다.

정밀 곡면/솔리드 STEP이 필요하면 정밀 CAD 편집 모드에서 선택하여 내보내세요. 메시 모드의 일부 부품 STEP 출력은 삼각형 평면으로 변환됩니다. 분해도·나란히 보기와 관계없이 실제 조립 위치로 저장합니다.

## 기능

- STEP/STP 열기, 부품 검색·선택·숨기기·단독 보기, 분해도와 나란히 보기
- STEP, STL, OBJ, GLB, FBX, SKP, 3MF, DWG, DXF, 3DS, USDZ, DAE, 3DM 가져오기/내보내기
- 부품 이동·회전·크기·이름·색상, 기본 솔리드/서페이스 연산, 선 드로잉 및 프로젝트 저장

모든 객체를 무손실로 변환하는 프로그램은 아닙니다. 각 형식의 지원 범위와 편집 제한은 소스 ZIP의 README.md에 명시되어 있습니다.

## 소스와 배포

이 저장소는 릴리스 배포용입니다. 각 [릴리스](https://github.com/GilwooKim/step-viewer-releases/releases)에 설치 파일, blockmap, latest.yml, SHA256SUMS.txt와 **STEP-Viewer-Source-<version>.zip**을 함께 제공합니다. 소스 ZIP에는 앱, 네이티브 어댑터, 필요한 상위 라이브러리 소스와 재빌드 안내가 포함됩니다. 사용자 CAD 파일은 포함하지 않습니다.
