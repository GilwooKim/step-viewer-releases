The original SOURCE-DEPENDENCIES.txt describes the pinned source revisions and
compiler versions. Its Windows-specific adapters and runtime replacement paths
do not apply to this iPad build; LibreDWG, OpenSKP and native Assimp are excluded.

To replace/relink an LGPL engine, build the corresponding JS and WASM from those
sources, replace its files in node_modules/occt-import-js/dist/ or
node_modules/replicad-opencascadejs/dist/, then run:
  npm run sync
  node scripts/configure-ios.mjs
Build ios/App/App.xcodeproj with Xcode and sign it with your own provisioning.
The app does not check engine hashes. iPadOS still requires an Apple-accepted
signature for installation; platform signing is separate from application code.

For public binary redistribution, preserve all notices and provide the
corresponding source archive as well as this app source. Runtime notices are
included in the bundled licenses directory.
