The main application's pinned npm source versions and integrity hashes are in
package-lock.json. npm ci; npm run build; npm run dist rebuilds the Windows app.
The source ZIP includes tools/ binaries so Rust is only required when changing the
native adapters. scripts/build-native.ps1 recompiles and copies the adapters.

Replacing LGPL libraries: close the application; replace both matching JS loader
and WASM files under resources/app.asar.unpacked/dist/vendor/. The filenames are
occt-import-js.js / .wasm, and replicad_single.js / .wasm. Native helper replacements
belong in resources/tools/. There is no signature check restricting modified builds.
